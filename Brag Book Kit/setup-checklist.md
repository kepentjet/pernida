# Brag Book Setup Checklist

Do this in the first weeks at a new company.

## Check the rules

- [ ] Read the confidentiality section of the employment contract
- [ ] Read the AI tool policy and the employee handbook
- [ ] Find out which AI tools are approved

## Check the tool

- [ ] Can it connect to work tools (email, calendar, chat, docs, tickets)?
- [ ] Can it run a task on a schedule?
- [ ] Can it read and write a file in company storage?

## Set it up

- [ ] Load `instructions.md` into the tool as a skill, custom assistant, or agent
- [ ] Upload `schema.md`, `playbooks.md`, and `sanitization-rules.md` with it
- [ ] Create the work copy from `brag-book-template.csv` in company storage
- [ ] Fill in the Storage section of `instructions.md`
- [ ] Map each data source to the columns it can fill:

| Source | Helps fill |
|---|---|
| Calendar | Stakeholders, Visibility |
| Sent email or chat | Contribution, Praises |
| Docs | Contribution, Skills |
| Tickets | Task, Business Impact |

## Calibrate

- [ ] Get the performance review criteria or the career level guide
- [ ] Adjust the Impact Categories to match what the company rewards
- [ ] Note the criteria for the next level, for promotion packets

## Schedule

- [ ] Weekly scan, every Friday afternoon
- [ ] Monthly export reminder, first Monday of the month

## Test

- [ ] Run one real win through Update mode
- [ ] Run Retrieve mode for a 1:1
- [ ] Run Export mode and review the result

## Before leaving a company

- [ ] Run a final export while you still have access
- [ ] Ask people who praised your work if you can list them as references
